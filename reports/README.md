# reports
One folder per issue: `issue-NNNN/report.md` + the full logs (`build-log.txt`, ...), linked from the issue.
report.md fields: Problem · Environment · Command · Expected · Actual · Error output · Investigation ·
Cause (confirmed / suspected / unknown) · Fix (fix or workaround) · Verification (with the output).
Keep separate problems separate. Never delete baseline evidence.
