Choose a licence for the public repository

**Problem:** this repository is public but has no licence file. Without one, the default is all rights reserved: others may look at the code but not reuse it.

**Options**
| Option | Effect |
|---|---|
| No licence (all rights reserved) | code visible, no reuse allowed; best if the game will be sold and the code kept exclusive |
| MIT for code, art and audio reserved | others may reuse the code; the game's art, names and audio stay protected (common for commercial indie games) |
| MIT for everything | anyone may reuse code and assets |

**Done when**
- [ ] the owner picks an option
- [ ] `LICENSE` added (or an all-rights-reserved note in README) and `docs/ASSET_LICENCES.md` updated
